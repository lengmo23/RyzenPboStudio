## Возможности

### Интерфейс и мониторинг

Левая панель переключает страницы **Настройка PBO**, **Тест стабильности**, **Разгон памяти** и **Журнал работы**; ниже показаны **Обзор системы** (процессор, память и живые FCLK/UCLK, материнская плата, BIOS и AGESA, драйвер видеокарты и ОС) и переключатель **Применять PBO при запуске**.

Сверху справа расположена панель мониторинга ядер, отображающая:

- Текущие значения и лимиты PPT, TDC, EDC и THM
- TEL/VID, Vdroop, Fmax и BCLK (`BCLK/BCLK2` при асинхронной шине)
- Состояние ядер по CCD: средняя загрузка и температура hotspot (`HOT`) каждого CCD, а также рейтинг CPPC (метки золотого / серебряного ядра), частота, эффективная частота (`EFF`), значение CO и Core VID по каждому ядру

### Настройка PBO

- **Curve Optimizer (CO)**: смещения по физическим ядрам, групповая регулировка `+/-` по столбцу, а также применение, обновление, сохранение и загрузка
- **Curve Shaper (CS)**: 5 диапазонов частоты (`MIN` / `LOW` / `MED` / `HIGH` / `MAX`) × 3 диапазона температуры (`LOW` / `MED` / `HIGH`), только на Ryzen 9000 (Zen 5)
- **Параметры PBO и Scalar**: одновременная запись FMax, PPT, EDC, TDC и PBO Scalar (1X–10X)
- **Применять PBO при запуске**: после включения при каждом входе в Windows автоматически применяет сохранённые CO / CS и сохранённые применённые FMax, PPT, EDC, TDC. Перед включением пройдите стресс-тест; после аварийной перезагрузки следующий запуск пропустит применение автоматически

### Тест стабильности

![Тест стабильности](testing.png)

#### Одноядерный буст и Выравнивание напряжения

Обе функции находятся справа на странице **Тест стабильности** и требуют процессор с AVX2 / FMA:

- **Одноядерный буст**: измеряет частоту, эффективную частоту, VID и Core VID каждого ядра при текущем CO, не меняя параметры
- **Выравнивание напряжения**: берёт лучшее ядро в каждом CCD за эталон, подбирает CO остальных ядер так, чтобы их напряжение на равной частоте выровнялось, и определяет потолок одноядерной частоты каждого CCD. Результат только подставляется в редактор CO без автосохранения — **перед использованием обязательно пройдите стресс-тест**

#### Стресс-тест

Стресс-тест использует **y-cruncher** в трёх режимах:

| Режим            | Описание                                                                                |
| ---------------- | --------------------------------------------------------------------------------------- |
| Одиночный        | Выбор одного теста из VT3, BKT, SVT, BBP, SFTv4, SNT, FFTv4, N63 или YC018              |
| Последовательный | Выполнение по порядку; по умолчанию `VT3 → BKT → SVT`, по 20 / 10 / 10 кругов           |
| Комбинированный  | Чередование выбранных тестов в каждом круге; по умолчанию `VT3`, `BKT`, `SVT`, 10 кругов |

Тесты, число кругов и длительность каждого круга настраиваются. `YC018` — ресурсоёмкий тест числа Пи для памяти, объём выбирается автоматически по ОЗУ и всегда задействует все ядра.

Охват:

| Охват      | Описание                                                       |
| ---------- | -------------------------------------------------------------- |
| Все ядра   | Нагружает все ядра одновременно                                |
| Выборочно  | Нагружает только отмеченные физические ядра                    |
| Один CCD   | Нагружает только выбранный CCD (только много-CCD процессоры)   |
| Каждый CCD | Полный прогон по очереди на каждом CCD (только много-CCD CPU)  |

Результаты одного CCD носят справочный характер; итоговую стабильность проверяйте на всех ядрах.

Регулировка CO:

- **Автоматический**: при ошибке y-cruncher сопоставляет сбойное логическое ядро с физическим, откатывает его CO (по умолчанию `+2`, можно задать от `+1` до `+5`) и перезапускает круг до прохождения
- **Ручной**: при ошибке лишь выводит уведомление и останавливает тест, ничего не меняя

### Разгон памяти

> Функция разгона памяти реализована при поддержке [Cat-girl-memoryOC](https://v.douyin.com/yMpmAidKqdY/) (`@纯爱出演小猪`).

![Разгон памяти](dramoc.png)

- **Данные SPD памяти**: сводка текущей памяти, модель и объём модулей по слотам, производитель чипов (ICs) и профили EXPO из SPD
- **Запись памяти и профили**: **Записать в BIOS**, **Сбросить**, **Импорт**, **Экспорт**; ниже показано число загруженных настраиваемых параметров и текущий статус
- **Напряжения и прочее**: `SOC`, `VDDP`, `VDDG CCD / IOD`, `VDD MISC`, `CPU VDDIO`, `DRAM VDD / VDDQ / VPP`, средние `DIMM Temp` (датчик SPD) и `DIMM Power` (PMIC; при наведении видны показания по модулям), `FCLK OC Mode` и поля только для чтения `BGS`, `BGS Alt`, `GDM`, `Cmd2T`. Напряжения SoC берутся из PM Table, напряжения памяти — с PMIC, обновление каждые 2 секунды
- **Тайминги DRAM**: `Memory Frequency`, `FCLK`, `UCLK DIV1 MODE`, `PowerDown Enable`, `Refresh Mode` и все тайминги контроллера памяти
- **Управление сигналами**: `ProcODT`, сила драйверов, `Rtt`, `Nitro`, `Robust Training`, `Interleave` и др.

#### Заполнение EXPO и импорт / экспорт

- **EXPO**: нажатие на профиль EXPO в SPD автоматически подставляет соответствующий пресет EXPO, повторное нажатие возвращает прежние значения. Для записи нужно нажать **Записать в BIOS**.
- **Экспорт**: сохраняет текущие цели в `.json` в папку `dram\` (имя формируется по платформе, частоте, CL и производителю чипов, например `DESKTOP-DDR5-6400-CL28-Hynix.json`). Каждая запись содержит имя функции `AMD_ACPI` и `"auto": true` либо сырое значение `value` BIOS (`label` и `display` только для чтения):

```json
{
  "format": "RyzenPboStudio.MemoryConfig",
  "version": 1,
  "source": "targets",
  "memoryType": "DDR5",
  "settings": [
    { "function": "Set Mem Clock", "label": "Memory Frequency", "auto": false, "value": 3200, "display": "DDR5-6400" },
    { "function": "Set VDDIO", "label": "DRAM VDD (V)", "auto": false, "value": 1400, "display": "1.400" },
    { "function": "Set TrrdL", "label": "TrrdL", "auto": true, "display": "Auto" }
  ]
}
```

- **Импорт**: поддерживает файлы `RyzenPboStudio.MemoryConfig` и конфиги памяти **Cat-girl memoryOC** (отдельный конфиг памяти или секция памяти из комбинированного профиля). Записи `Auto` возвращают текущую настройку BIOS; неподдерживаемые платой параметры выводятся в строке состояния. Нажмите **Сбросить**, чтобы вернуть все цели к текущим значениям BIOS

#### Записать в BIOS

- Параметры записываются через WMI-интерфейс материнской платы `AMD_ACPI`. Программа не может отправлять значения Auto
- **Записать в BIOS** заблокирована по умолчанию; сначала включите **Режим эксперта** в **Настройках**
- Потолок `CPU VDDIO` — `1.500 V`; перед записью нужно задать целевое значение, оставлять Auto нельзя
- Окно подтверждения помечает явно аномальные цели (на границе min/max BIOS или в 2 и более раз выше / в 2 и более раз ниже текущего значения). Перед записью проверяются ID функций прошивки и текущие ключевые параметры, текущие значения BIOS автоматически сохраняются в `profiles\memory_backup_<время>.json` (можно импортировать обратно); команды отправляются по одной (остановка при ошибке), после чего каждый параметр перечитывается, а сырые команды и ответы пишутся в `logs\acpi-command-trace.jsonl`
- Изменения вступают в силу после **перезагрузки и завершения тренировки памяти**. **Неверные параметры могут привести к чёрному экрану и невозможности запуска**: на настольном ПК нужен сброс CMOS; на ноутбуках обычно нет внешней кнопки сброса и может потребоваться разборка для отключения основного аккумулятора и батарейки CMOS. Программа не может восстановиться сама

### Журнал работы и восстановление после сбоев

![Журнал работы](logging.png)

- **Журнал работы**: полный журнал открывается на странице **Журнал работы** (справа на **Настройка PBO** есть синхронное мини-окно), где фиксируются круги и скорость y-cruncher, сопоставление сбойных логических и физических ядер, откаты CO и записи в BIOS; каждый запуск сохраняется в `logs\`
- **Восстановление после сбоев**: при зависании или отключении питания во время теста программа автоматически запускается после перезагрузки, восстанавливает лимиты PBO и Curve Shaper, откатывает CO на один шаг (если после сбоя CO уже изменили вручную — продолжает с ручными значениями) и возобновляет прерванный этап; отменить можно в любой момент. Для ночных тестов без присмотра включите автовход в Windows

### Настройки и языки

Нажмите **значок шестерёнки** внизу левой панели, чтобы открыть **Настройки**:

- **Общие**: язык, подтверждать выход и **Режим эксперта** (пропускает обычные окна тестов / восстановления / автозапуска и разблокирует **Записать в BIOS**)
- **Обновления**: проверять обновления при запуске
- **Мониторинг**: интервал обновления (`100–10000 мс`, по умолчанию `500 мс`)
- **Данные**: быстрый переход к папкам `profiles` и `logs`

Английский язык встроен, а в `lang\` лежат 9 переводов (`zh-Hans`, `zh-Hant`, `ja`, `ko`, `de`, `es`, `fr`, `pt-BR`, `ru`). По умолчанию используется язык Windows (резервный — английский). Каждый `<код>.ini` оформлен как `Английский текст=перевод` (сохраняя `{0}` и т. п.); чтобы добавить язык, скопируйте файл, переименуйте по коду языка и измените `name=` под `[meta]`. Смена языка применяется после перезапуска.

| FMax            | Нет                           | Да                 | Да                 |
| Рейтинг CPPC    | Требуется включить CPPC в BIOS | Да                 | Да                 |

## Использование

1. Скачайте нужный архив из [Releases](https://github.com/lengmo23/RyzenPboStudio/releases) и распакуйте в любую папку:
   - **`-lite.zip`**: с y-cruncher, требуется установленный .NET 8 Desktop Runtime
   - **`-net8contained.zip`**: со встроенными .NET 8 Runtime и y-cruncher, запускается без установки .NET 8
   - `-update.zip` и `-net8patch-rt*.zip` нужны только для автообновления, не содержат y-cruncher и не подходят для первой установки
2. Установите [PawnIO](https://pawnio.eu) и запустите `AMD Ryzen PBO Studio.exe` от имени администратора
3. На странице **Настройка PBO** убедитесь, что частоты ядер, CO и показатели мощности считываются нормально
4. Перейдите в **Тест стабильности**, выберите режим, охват и способ регулировки CO и нажмите «Старт»
5. После прохождения всех тестов **Журнал работы** выведет прошедшие CO и CS, а итоговый CO также запишется в `profiles\final_offsets.txt`
6. Для настройки памяти перейдите в **Разгон памяти**, измените или импортируйте цели (можно сначала подставить EXPO), включите **Режим эксперта** в **Настройках**, нажмите «Записать в BIOS» и перезагрузите ПК для тренировки памяти

В той же папке программа использует три каталога:

- `logs\`: журналы каждого запуска, логи y-cruncher и записи `AMD_ACPI`
- `profiles\`: история CO, состояние восстановления, профили CO / CS, калибровка, настройки и резервные копии памяти BIOS
- `dram\`: папка по умолчанию для импорта / экспорта профилей разгона памяти (комплектные пресеты тоже лежат здесь)

## Предупреждение о рисках

И PBO, и разгон памяти влияют на стабильность системы. Неверные настройки могут вызвать ошибки вычислений, зависания, синие экраны, перезагрузки, потерю несохранённых данных или чёрный экран без загрузки (на настольном ПК нужен сброс CMOS, на ноутбуке может потребоваться разборка и отключение основного аккумулятора и батарейки CMOS). Длительная нестабильная работа способна повредить железо и повлиять на гарантию. **Сохраните файлы перед тестом, не пользуйтесь ПК во время теста и проверьте все целевые значения перед записью в BIOS.**

## Сборка из исходного кода

```powershell
dotnet publish .\RyzenPboStudio\RyzenPboStudio.csproj -c Release -r win-x64 `
  --self-contained false `
  -p:DebugType=None -p:DebugSymbols=false `
  -o .\memoc
```

Сборка выводится в `memoc\`, всю папку можно распространять как есть (не один файл). Если в корне репозитория есть `y-cruncher v0.8.7.9547b\` или `dram-presets\`, они автоматически копируются в `tools\y-cruncher\` и `dram\`; иначе этот шаг пропускается.
