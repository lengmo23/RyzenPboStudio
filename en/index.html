AMD Ryzen
PBO Studio

Tune AMD Ryzen 5000, 7000, and 9000 series processors on Windows. Monitor your CPU and memory, adjust PBO, Curve Optimizer, and Curve Shaper, run y-cruncher stability tests, or edit memory settings and write them to BIOS.

Live monitoring

System Overview in the sidebar shows the CPU, memory capacity, live FCLK and UCLK, motherboard model, BIOS and AGESA versions, GPU and driver, and Windows version. The live monitor appears at the top of PBO Tuning, Stability Test, and Run Log. It collapses on Memory OC.

Power, current, and temperature
Current readings and limits for PPT (package power), TDC (sustained current), EDC (peak current), and THM (temperature).
Voltage and frequency
TEL, VID, Vdroop, FMax, and BCLK. Systems with asynchronous base clocks show BCLK and BCLK2 separately.
CCD and per-core readings
Each CCD shows average utilization and hotspot temperature. Each core shows its CPPC rank (with gold and silver markers), frequency, effective frequency (EFF), CO, and Core VID.

Use EFF to see a core's effective frequency during a test. If CPPC rankings are blank on Ryzen 5000, check whether CPPC is enabled in BIOS.

PBO tuning

Curve Optimizer and Curve Shaper

Curve Optimizer (CO) adjusts the curve offset for each physical core. Edit individual cores, or use + and − to adjust a whole column. On supported Ryzen 9000 series CPUs, Curve Shaper (CS) lets you adjust the curve across five frequency bands (MIN, LOW, MED, HIGH, MAX) and three temperature bands (LOW, MED, HIGH).

Apply
Apply the values in the editor to the running system.
Refresh
Read the current values from the hardware.
Save
Save the edited values to profiles\co_profile.json or profiles\cs_state.json.
Load
Load a saved profile into the editor. Click Apply to activate it.

Frequency, power, current, and Scalar

At the bottom of the page, set FMax (MHz), PPT (W), EDC (A), TDC (A), and PBO Scalar (1X–10X), then click Apply on the same row. FMax and Scalar availability depends on the CPU and firmware. The program records FMax, PPT, EDC, and TDC when a test starts or you apply the limits manually, so it can restore them when resuming a test.

Apply PBO at startup

After passing a stability test, save a CO profile matching the current CPU's core count and save a CS profile if needed. Then turn on Apply PBO at startup in the sidebar. At each Windows sign-in, the program applies the saved CO and supported CS values, along with the last FMax, PPT, EDC, and TDC limits applied on the PBO page. It writes only limits that differ from the current values and retains the firmware's Scalar setting.

If the system restarts unexpectedly soon after applying settings at startup, the program skips the next startup apply. Check Run Log for the reason and review your saved settings.

Write PBO settings to BIOS

Write to BIOS on the PBO Tuning page is available on desktops only. Unlock the feature in the program, enable Expert mode, and stop any running test or measurement. The program checks the motherboard interface, previews the PBO, CO, and CS settings it can write, and explains any skipped items. After confirmation it sends the settings one at a time. They take effect after a restart. Firmware support varies, and the program flags support as experimental on platforms other than Zen 5.

Some firmware may lose the sign of a positive CO offset after a restart. If a write fails partway through, earlier writes may still take effect. Check Run Log and the BIOS before trying again.

Stability testing

y-cruncher test plans

Single test
Choose VT3, BKT, SVT, BBP, SFTv4, SNT, FFTv4, N63, or YC018. For regular stress tests, set the round count and duration per round.
Sequential
Complete all rounds of one test before starting the next. The default is VT3 for 20 rounds, BKT for 10, then SVT for 10. You can edit the tests, order, round counts, and duration per round.
Combined
Run each selected test in turn within every round. The default rotates VT3, BKT, and SVT for 10 rounds. You can change the tests, total rounds, and the common duration per round.

Choose All cores or select individual physical cores under Custom. On a multi-CCD processor, select one CCD or use Each CCD to run the full test on each CCD in turn. The multi-test plan and the CO backoff step have separate settings buttons. Click Stop to end a run.

Automatic and manual CO adjustment

Apply the CO values you want to validate in PBO Tuning, then open Stability Test.

Auto
When y-cruncher identifies a failing logical core, the application maps it to its physical core, increases that core's CO by the configured backoff step (default +2, adjustable from +1 to +5), and reruns the current test or combined plan. CO backoff stops at +30 if the test keeps failing.
Manual
The application reports the error and stops, preserving the current CO values so you can troubleshoot the CPU or memory settings manually.

After all rounds pass, Run Log shows the final CO and available Curve Shaper data. profiles\final_offsets.txt records the test plan, scope, and passing per-core CO values. After a single-CCD test passes, run an all-core test to validate the full configuration.

Single Core Boost and Voltage Alignment

Both tools are on the right side of Stability Test and require AVX2 and FMA. Stop any running stress test before starting a measurement.

Single Core Boost
Loads one core at a time with the current CO and records its frequency, effective frequency, VID, and Core VID. Your tuning settings stay in effect.
Voltage Alignment
Starts each core at the same CO, then picks a reference core for each CCD. It adjusts other cores toward similar voltages at the same frequency and looks for the CCD's single-core frequency plateau. Cores that produce computation errors are backed off. The program applies CO changes during the run and fills the editor with the resulting values. Stress-test the result before saving it manually.

At the standard base clock, alignment starts at CO 0. When the application detects a raised CPU base clock, the confirmation dialog lets you set the starting CO. The result table and log show per-core measurements and alignment status. Click Stop to end the run.

YC018 and memory validation

YC018 is a memory-intensive Pi benchmark available as a single test. It selects 2.5, 5, or 10 billion digits based on installed memory and uses all cores. The round count sets the number of runs. YC018 ignores the duration and core scope settings. To isolate memory changes, keep CO fixed, choose Manual, confirm the live frequency and timings after restarting, then validate with suitable memory stability tests.

Memory overclocking

Check your motherboard's recovery procedure before writing

Unstable memory settings can cause data errors, freezes, or a black screen at boot. Save important work and check your system manual for CMOS reset or BIOS recovery instructions before making changes.

Readings and configurable settings

Memory SPD Info
Capacity, channel count, frequency, primary timings, Cmd2T, each slot's module model and capacity, DRAM IC vendor, and EXPO profiles read from SPD.
Misc & Voltages
SoC, VDDP, VDDG CCD / IOD, VDD MISC, CPU VDDIO, DRAM VDD / VDDQ / VPP, and FCLK OC Mode. This panel also shows the read-only BGS, BGS Alt, GDM, and Cmd2T values, plus average DIMM temperature and power when supported. Hover to see individual DIMM readings.
DRAM Timing Control
Memory Frequency, FCLK, UCLK DIV1 MODE, PowerDown Enable, Refresh Mode, and primary, secondary, and other timings read from the memory controller. BIOS support determines which settings you can edit.
Signal Control
ProcODT, drive strengths, Rtt termination, Nitro RX / TX / Ctrl Line, Robust Training, Interleave, and related settings.

The page refreshes about every two seconds and displays live voltage and DIMM data when the hardware supplies it. Memory Write & Profiles shows the number of configurable settings and the current operation status.

Read SPD and set target values

  1. Open Memory OC to see the modules, DRAM ICs, EXPO profiles, and available controls. Current and Target are shown side by side. Blue targets are pending changes.
  2. Click an EXPO profile in the SPD panel to fill supported targets for frequency, primary and refresh timings, DRAM VDD and VDDQ, CPU VDDIO, and Nitro. Click the same profile again to undo that fill.
  3. Edit values individually or click Import to load a JSON file exported by this program, a standalone Cat-girl memoryOC profile, or the memory section of a combined profile. The status line lists skipped items. Click Revert to reset the targets to the current BIOS settings.
  4. Click Export to save the targets to a JSON file. The default directory is dram\. The filename includes the platform, frequency, CL, and DRAM IC vendor when available.

EXPO, imports, and manual edits change the targets in the editor. Whether a preset runs reliably depends on your CPU, motherboard, BIOS, and memory modules.

Write to BIOS and restart

  1. Open Settings with the gear icon at the bottom left. Under General, enable Expert mode.
  2. If the CPU VDDIO target is still Auto, set a value appropriate for your system. The program caps CPU VDDIO at 1.500 V. Click Write to BIOS and review the changes and flagged values in the confirmation dialog.
  3. After confirmation, the application checks the firmware interface and relevant settings, saves profiles\memory_backup_<time>.json, then writes and reads back each item through the motherboard's AMD_ACPI WMI interface. A failed validation or backup stops the process before any writes.
  4. Review the result, restart your computer, and give it time to complete memory training. Open the program again to check live frequency and timings, then run a stability test.

If the write fails partway through, some settings may already have been written. Review Run Log and the values read back from firmware before deciding how to recover.

Logs and recovery

Find logs and configuration files

Run Log shows the full log, also mirrored on the right side of PBO Tuning. It records y-cruncher rounds, timings and speeds, failing-core mappings, CO backoffs, and BIOS writes. Clear log clears the displayed log. Files in logs\ remain available.

logs\
Application sessions, y-cruncher output, and firmware commands and responses in acpi-command-trace.jsonl.
profiles\
CO and CS profiles, test plans and results, write history, recovery state, program settings, and memory BIOS backups.
dram\
Default folder for importing and exporting memory JSON files. Bundled presets, when included, are also stored here.

Resume after an unexpected restart

The program saves the test plan, stage, core scope, and CO history. After a freeze or power loss, a startup task attempts to resume testing when you sign in to Windows. It prioritizes the interrupted test, restores the recorded PBO limits and supported CS values, and backs off the CO of each enabled core by one step. If you apply CO manually after restarting, the test resumes with your manual values.

In standard mode, you can cancel during the 30-second countdown before automatic resume. After 10 consecutive automatic resume attempts followed by unexpected restarts, the program requires manual intervention. Canceling preserves the recovery state, so you can resume later with Start on Stability Test. Unattended recovery requires Windows automatic sign-in.

Settings and updates

General, Monitor, and Data

Click the gear icon at the bottom left to open Settings.

General
Choose a language and whether to confirm before exiting. Expert mode skips routine test, recovery, and startup apply prompts and unlocks Write to BIOS on Memory OC. BIOS writes still require confirmation.
Monitor
Set the CPU monitor refresh interval from 100 to 10,000 ms. The default is 500 ms.
Data
Open the profiles and logs folders.

The application follows the Windows display language by default and falls back to built-in English. It ships with Simplified Chinese, Traditional Chinese, Japanese, Korean, German, Spanish, French, Brazilian Portuguese, and Russian translations. Restart the program after changing the language.

Update checks and toolbar

Enable Check for updates at startup in Settings, or click the download icon at the bottom left to check manually. The application reads the latest stable release and notes from GitHub. You can install the update or skip that version. The updater selects a package based on whether your installation bundles .NET 8, restarts the program, and keeps your logs and profiles. If replacing files fails, it attempts to restore the backup.

About shows the version and author information. The coffee cup icon opens the optional sponsorship panel.

Frequently asked questions

The program won't start

Confirm you use Windows x64, have installed PawnIO, and are running as administrator. For lite, check that you installed .NET 8 Desktop Runtime x64. If a DLL is missing, extract the entire package again.

Memory BIOS writing is disabled or there are no adjustable settings

Enable Expert mode first. If there are still no adjustable settings, check the status line and firmware detection entries in Run Log. Check your motherboard model and BIOS version, since writable settings vary by firmware.

Windows still boots. How do I restore the previous memory settings?

Click Import and select profiles\memory_backup_*.json. Review the values that can be restored, write them, and restart. To return a setting you wrote manually to Auto, make the change in your motherboard's BIOS.

The screen is black after restarting, and I can't reach BIOS or Windows

Allow the time your motherboard manual specifies for memory training. If the system still cannot complete its power-on self-test, follow the motherboard or system manufacturer's instructions to clear CMOS or restore BIOS defaults. For laptops without an external reset option, consult the service manual or contact the manufacturer. Recovery through the program requires Windows to boot.

Report a problem

Include the software version, CPU, motherboard, BIOS version, steps to reproduce the issue, and relevant log excerpts.
